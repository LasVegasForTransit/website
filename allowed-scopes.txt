# Allowed commit scopes for the LVBT website
#
# This is a single Astro site, not a platform. Only true architectural
# boundaries get a scope; everything else stays scopeless.
#
# Format: one scope per line, lowercase-kebab-case. Comments start with #.
#
# Adding a scope here is a deliberate act. Page slugs, component names,
# short-lived features, dep bumps, and vendor tags must NOT be added.
#
# See docs/standards/commit-scopes.md for the full rationale.

content     # MDX/copy in src/content/
ci          # .github/workflows and composite actions
docs        # docs/ directory (repo documentation, not site copy)
dx          # hooks, lint config, dev scripts, local-dev tooling
