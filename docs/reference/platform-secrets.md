# Platform secrets

This page lists every server-side secret the website and the Organizing Platform use, what each one is for, and where to get it. Read it when you set up a new deployment, rotate a key, or see a `503 service_unavailable` that names a missing secret.

A secret is a value, such as an API key, that lets the site act on LVBT's behalf in another service. Secrets are never committed. They are stored in Cloudflare and GitHub, and the site reads them at request time (see the [glossary](./glossary.md#env-var)).

## Set them with bootstrap

You don't need to set secrets by hand. Run:

```sh
pnpm bootstrap --phase secrets
```

It checks the Worker, the Pages project and the `worker-candidate` GitHub environment, and prints which secrets are missing where. Then it asks for each missing value once and stores it everywhere it is needed. Values it can make itself, such as random signing keys, are generated for you. Leave a prompt empty to skip that secret for now; re-run the command later to finish.

To only see the report, without changing anything:

```sh
pnpm bootstrap --doctor --phase secrets
```

**Before you start:** sign in to Wrangler (`pnpm exec wrangler login`) and to GitHub (`gh auth login`). You need Cloudflare access to the LVBT account and admin access to the website repository.

## Where each secret lives

| Target                                | What it serves                                                       |
| ------------------------------------- | -------------------------------------------------------------------- |
| Pages project `lvbt-website`          | Production today                                                     |
| Worker `lvbt-website`                 | Production after the move from Pages to Workers, and main candidates |
| GitHub environment `worker-candidate` | The workflow that uploads main candidates for comparison with Pages  |

Pull request previews run on the separate `lvbt-website-preview` Worker without these secrets, so preview API routes answer `503` by design.

## The secrets

The single source of truth is `scripts/bootstrap/config/platform-secrets.ts`. The table below mirrors it.

| Secret                            | Used for                                        | Where to get it                                                                                           |
| --------------------------------- | ----------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| `LVBT_BEEHIIV_API_KEY`            | Joining, newsletter signup, mailing list sync   | Beehiiv → Settings → Integrations → API                                                                   |
| `LVBT_BEEHIIV_PUBLICATION_ID`     | Same                                            | Beehiiv → Settings → Integrations → API, the `pub_` ID                                                    |
| `LVBT_MEMBERSHIP_INTAKE_SECRET`   | The Google Form fallback                        | The form's Apps Script → Project Settings → Script Properties                                             |
| `LVBT_NOTION_API_KEY`             | Staff follow-up in Notion, transit news         | notion.so/profile/integrations → the LVBT intake connection                                               |
| `LVBT_NOTION_DATA_SOURCE_ID`      | Staff follow-up in Notion                       | The membership intake database → ••• → Copy data source ID                                                |
| `LVBT_TRANSIT_NEWS_INTAKE_SECRET` | Transit news intake                             | Generated by bootstrap; paste it into the Notion automation's `Authorization: Bearer` header              |
| `LVBT_SIGN_IN_SECRET`             | Hashing member sign-in codes                    | Generated by bootstrap                                                                                    |
| `LVBT_LINK_SIGNING_SECRET`        | Signing one-purpose links such as email removal | Generated by bootstrap                                                                                    |
| `LVBT_RESEND_API_KEY`             | Sign-in codes and other transactional email     | resend.com → add the domain `notify.lasvegasfortransit.org` with Cloudflare auto-configure → API Keys     |
| `LVBT_GOOGLE_OAUTH_CLIENT_ID`     | Staff and volunteer Google sign-in              | Google Cloud → Credentials → OAuth client (Web), consent screen Internal                                  |
| `LVBT_GOOGLE_OAUTH_CLIENT_SECRET` | Same                                            | The same OAuth client                                                                                     |
| `LVBT_ACCESS_TEAM_DOMAIN`         | The staff console's Cloudflare Access check     | Cloudflare Zero Trust → Settings → Team domain                                                            |
| `LVBT_ACCESS_AUD`                 | Same                                            | Zero Trust → Access → Applications → the staff console → Application Audience (AUD) Tag                   |
| `LVBT_DISCORD_APPLICATION_ID`     | Discord linking and roles                       | discord.com/developers → the LVBT application → General Information                                       |
| `LVBT_DISCORD_PUBLIC_KEY`         | The Discord link command                        | Same page                                                                                                 |
| `LVBT_DISCORD_CLIENT_SECRET`      | Connecting a Discord account                    | The application → OAuth2                                                                                  |
| `LVBT_DISCORD_BOT_TOKEN`          | Discord roles                                   | The application → Bot → Reset Token; also turn on Server Members Intent                                   |
| `LVBT_DISCORD_GUILD_ID`           | Discord roles                                   | Discord developer mode → right-click the server → Copy Server ID                                          |
| `LVBT_GOOGLE_SERVICE_ACCOUNT_KEY` | Volunteer Workspace accounts and groups         | Google Cloud service account JSON key with domain-wide delegation for the Directory user and group scopes |
| `LVBT_GOOGLE_ADMIN_SUBJECT`       | Same                                            | A Workspace super admin address the service account acts as                                               |
| `LVBT_GIVEBUTTER_API_KEY`         | Donor support                                   | Givebutter → Settings → Integrations → API                                                                |

The redirect addresses to register with Google and Discord are in each prompt's instructions when you run bootstrap.
