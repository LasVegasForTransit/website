## Why this project

RTC publishes plenty of data. What's missing is one public dashboard where a journalist, a concerned parent, or a curious neighbor can see how the system is doing at a glance.

The People's RTC Dashboard fills that gap. It pulls from public sources — GTFS feeds, RTC public reports, FTA National Transit Database — and renders the system's state in a way any Las&nbsp;Vegan can read at a glance. Ridership. On-time performance. Recent route changes. Board agenda items affecting service. Updated nightly. Open to download.

## Approach

- Cloudflare Worker cron pulls public sources nightly into D1; static rendering at the page edge
- Visual design optimized for "scan first, drill down second" — not a tableau wall of charts
- Cite every number with its source and timestamp on the dashboard itself
- Open the data outputs so partner orgs and journalists can reuse them in their own work
